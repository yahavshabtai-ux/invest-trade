
# PaperTrade Pro

אתר דמו למסחר מהיר בסגנון ויזואלי שמזכיר TradingView Paper Trading.

## מה יש בפנים
- עיצוב כהה ומסודר
- Watchlist בצד
- Chart גדול עם candlesticks
- Order Ticket
- Buy / Sell
- בחירת משך עסקה: שניות / דקות / שעות / ימים
- יתרת דמו
- היסטוריית עסקאות

## העלאה ל-GitHub Pages
1. מעלים את כל הקבצים לריפו
2. נכנסים ל-Settings
3. לוחצים Pages
4. בוחרים:
   - Deploy from a branch
   - main
   - /(root)
5. Save
